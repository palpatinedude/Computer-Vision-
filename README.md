Geometric Transformations — Exercise 2
📖 Overview

This project corresponds to Exercise 2 and focuses on the application of geometric transformations in digital image processing. The exercise explores how affine transformations can be used to manipulate images and generate animated sequences using MATLAB.

🎯 Objectives

The main objectives of Exercise 2 are:

To understand the principles of geometric transformations in images

To apply affine transformations such as scaling, rotation, translation, and shearing

To create composite images and animated sequences

To evaluate the effect of different interpolation methods

To use masking techniques for realistic image composition

🧩 Exercise Structure
🔹 Function Familiarization

The exercise begins with an introduction to fundamental image processing functions. These functions are used for reading images, defining geometric transformations, controlling spatial references, and visualizing image sequences.

🔹 Image Scaling Composition

Multiple scaled versions of the same image are created using different scaling factors. The scaled images are then combined into a single composite image, demonstrating how scaling affects image size and appearance.

🔹 Periodic Shearing Transformation

A periodic image sequence is generated by applying horizontal shearing transformations. The shearing parameter varies smoothly over time, producing a continuous animation effect.

🔹 Fixed-Base Horizontal Shearing

Horizontal shearing is applied while ensuring that the base of the image remains fixed. A periodic rule is used to control the variation of the shearing parameter, resulting in realistic and stable motion.

🔹 Image Animation with Masking

An animated sequence is created using rotation, scaling, and translation transformations. Masking techniques are applied to isolate specific parts of the image, enabling natural composition and visually consistent motion.

🔹 Interpolation Method Comparison

The same geometric transformations are applied using different interpolation methods, such as nearest neighbor, linear, and cubic interpolation. The results are compared in terms of visual quality and smoothness.

🔹 Object Motion and Depth Simulation

A final animation is produced in which an object moves across a background following a modified trajectory. Gradual scaling is applied to simulate depth, giving the impression that the object moves toward the horizon and eventually disappears.
